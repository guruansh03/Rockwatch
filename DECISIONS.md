# DECISIONS

- **D-001 (P0)** Exact-day event = `Date_Min` set and (`Date_Max` empty **or `Date_Max == Date_Min`**). Same-day range carries no extra uncertainty; simplest valid reading. Folded into `exact`; revisit at CP1.
- **D-002 (P0)** `Date_Max < Date_Min` rows: swap; count reported in profile.
- **D-003 (P0)** `Lon_W` sign: if >50% of values positive, negate whole column; residual positive count reported.
- **D-004 (P0)** Type family: lowercase substring match, priority fall > flow > slide > unknown; nonempty unmatched → `other`, empty → `unknown`. "debris avalanche" → flow. Exclusions (gully, avalanche chute, snow avalanche, sinkhole, subsidence, erosion) checked first. Table in `config/default.yaml`; top-40 raw LS_Type→family mapping printed in profile for CP1 review.
- **D-005 (P0)** Region unit = square bbox (2° / 3°, 0.5° step) over 0.25° zone centres, greedy non-overlapping, ranked by C≥C_min exact-dated positive zone-days since 1950. No state polygons (no geopandas). Inventory names shown for state context.
- **D-006 (P0)** Split proposal: boundaries at 60/20/20 cumulative positive-zone-day quantiles, 30-day gap after train and val; start 1950-01-01; end = last event date in region. Heuristic thresholds ≥150 total / ≥30 test (enough for bootstrap CIs with ~dozens of storm clusters); storm-cluster counts also reported since effective sample size = clusters, not zone-days.
- **D-007 (P0)** Sandbox egress initially blocked data hosts → stopped per §1/§3; user downloaded inventory + DS746 natively. Open-Meteo + ComCat now reachable from local VM.
- **D-008 (P0)** v3 zip ships two CSVs (`us_ls_v3_point.csv` 310,774 rows, `us_ls_v3_poly.csv` 680,497 rows). Loader concatenates both, adds `geom`. `Notes`, `Inv_URL` never loaded. `Lon_W` already negative → no flip.
- **D-009 (P0)** Regions ranked by exact-dated C≥3 positive zone-days **excluding** EQ-triggered inventories (28,922 of 48,093 exact C≥3 events are "USGS Earthquake-Triggered Ground Failure": few single days with hundreds of zone-days → tiny effective sample, not rain/thermal-forecastable). EQ events in-region still reported per split; kept for the with/without-EQ breakdown.
- **D-010 (P0)** Train start = Jan 1 of first year with ≥ max(2, 0.1×median annual) positives (reporting-coverage start). Zone-days before an inventory starts reporting are not true negatives. Split end = last positive in region.
- **D-011 (P0)** Type map additions after seeing real values: `mudslide`, `torrent`, `debris_flow` → flow; `rock_fall`, `rock avalanche`, `rock and ice avalanche` → fall (rock-origin; flag at CP1); `manmade fill` excluded. Dates after 2025-12-31 (1 row, 2041) → undated.
- **D-012 (P0)** Yosemite DS746 parsed from `Master` sheet (header row found by "Year"); exact = Y/M/D all present; narrative/reference columns dropped (untrusted). No coordinates → single valley zone.
- **D-013 (CP1, user-confirmed 2026-10-29)** Main region A = Anchorage/Seward Hwy AK bbox [59.5,62.5)×[−150.5,−147.5); splits train 2006-01-01→2015-02-10, val 2015-03-13→2018-03-15, test 2018-04-15→2022-06-30; C_min=3 (+≥5 breakdown); type map accepted; Yosemite DS746 track included now (splits train 1951-01-01→2008-01-08, val 2008-02-08→2010-04-03, test 2010-05-04→2011-12-31, same coverage/quantile rule).
- **D-014** Region B (Puget/NW OR robustness) dropped by user: Open-Meteo free quota. Measured: a 6,060-day 6-variable request costs ≈270 weighted calls (hourly 429 after ~18 requests); B at spec = 144 zones × 1950–2023 ≈ 6–11 days of quota.
- **D-015** `regional_extent` = fraction of zones with P3 > that zone's val-period median P3 (spec: rain-group evidence > val median). P3 replaces the fitted rain contribution to avoid circularity; weather-only, no labels.
- **D-016** Zero-feature zone sample drawn from 8-neighbours of feature cells (avoids open-water cells; elevation API host blocked). Ratio 0.25 → A: 56 feature + 14 zero zones.
- **D-017** Weather fetched [train_start−35 d, test_end], `timezone=auto` (local days, matching inventory local dates). Quake times converted UTC→region tz (`regions.*.tz`) before day bucketing. Missing weather never filled; flagged `wx_missing`.
- **D-018** Exact events in cells not selected by leakage-safe zone selection are dropped from labels and counted in the data card (A partial build: 541 of 3,376) — consequence of never using val/test events for zone selection.
- **D-019** Weather fetch driven in hourly budgeted batches (resumable cache, stops on 429). Python on dev VM is 3.10; code kept 3.10-compatible.
- **D-020 (P2)** Hysteresis "de-escalate after 2 consecutive lower days" ⇒ active[d] = max(raw[d], raw[d−1]) per zone (pure fn, shared with AlertAgent). Level in force on day d from data ≤ d−1 = active[d−1].
- **D-021 (P2)** Matching details beyond §10 text: episodes overlapping a short-range window [Date_Min−1, Date_Max] count TP; day-level hit = exact event on a or a+1, or a inside a short-range window; F1_at = F1(episode precision, recall_at incl. short-range). Also reported: F1_before, F1_day (day precision) because episode precision can be inflated by long episodes.
- **D-022 (P2)** Block bootstrap: region-wide event dates within 3 d → storm cluster; blocks = cluster windows ±3 d plus the quiet stretches between; resample blocks (1,000), percentile 95% CI from per-block tallies.
- **D-023 (P2)** Fusion: log1p on P1/P3/P15/P30/API/intensity/eq_count; quake distance → proximity max(0, 1−d/100); standardise on all train rows; negatives sampled 1:50 (A has fewer → all used, ratio recorded); C ∈ {0.01, 0.1, 1} chosen by val average precision; Platt fitted on the deployed clipped-contribution logit over the full val split.
- **D-024 (P2)** Thresholds: grid = val-p quantiles 0–99.95% (200); t1 = largest t with val recall_at ≥ 0.9 (capped at t2); t2 = argmax val F1_at; t3 ≥ t2 with corroboration (≥2 dynamic modalities > 0). Baselines: B1/B3 cut-offs argmax val F1_at; B3 = train zone×month rate shrunk to region×month (k=30); B4 raw rate f' = 1−√(1−f) so post-hysteresis alert-day fraction ≈ RockWatch's.
- **D-025 (P2)** `eval --split test` refused without `--final`; `--final` refused if a test report exists unless `--force-rerun-with-reason` (logged to reports/final_runs.log).
- **D-026 (P3)** Extra topics beyond §9.2: `sim.clock` (replay ticks), `agents.control` (stop), `eval.live` (EvaluatorAgent stream). Envelope validated by pydantic; unknown topics rejected.
- **D-027 (P3)** Redis backend cut (cut list #1): `bus/redis_bus.py` is an explicit stub; `--bus redis` exits with a message.
- **D-028 (P3)** Regional-extent comparison rounds P3 and the val median to 1e-6 mm in batch and live so pandas-rolling vs numpy sums cannot flip ties (found by the parity test). Panel rebuilt + models retrained.
- **D-029 (P3)** Watermarks are deadlines after each day's tick (fraction of speed): evidence 0.9, quality 0.8, context 1.0, fusion 1.2, alert 1.5. Normal days close as soon as inputs are complete; deadlines only fire under faults/lag. Late readings after a deadline are dropped (realistic). Engine pauses 2 sim-days before the first tick.
- **D-030 (P3)** QualityAgent liveness is applied at fusion: no quality summary for day d by the fusion deadline (or supervisor marks `quality` stale) → rain/thermal quality forced to ≥ degraded (w=0.5). Evidence with NaN window features (after a gap) is published `degraded`, never silently `ok`. Context excludes non-ok rain evidence and reports degraded.
- **D-031 (P3)** Bus delivery is at-most-once (offset advanced on poll). Restarted evidence agents warm-start from the cached archive up to the current sim day; AlertAgent restores hysteresis/episodes from its last `daily_state`; Supervisor restarts only agents flagged `--auto-restart` (via the sqlite registry).
- **D-032 (P3)** Parity is tested with the same agent classes in a deterministic in-process runner (memory bus) over 30 val days: contributions, p and levels match batch to 1e-9; multi-process runs use the identical step functions.
- **D-033 (P3)** Dev replay scenario `dev_val` = A, 2017-08-20 + 60 d (validation period). Demo scenarios from the test period are picked at CP2.
- **D-034 (P4)** Claude Haiku 5.5 / Sonnet 5.5 (IDs `claude-haiku-5-5`, `claude-sonnet-5-5`, verified on platform.claude.com 2026-10-29) reject `temperature`/`top_p` with a 400; the Anthropic provider omits them. Determinism/reproducibility via the response cache. Forced tool choice not used.
- **D-035 (P4)** Batch `eval --llm on`: verifier applied to provisional L2+ rows of the evaluated period, highest-p first, up to `max_llm_calls` (500); the rest keep the deterministic level and are counted as FALLBACK_CAP. Cap counts requests, so reruns hit the cache identically.
- **D-036 (P4)** Hindi alert text cut (cut list #4). Composer runs as its own agent process (`composer`), publishes `alerts.active/message`; renotifications are not re-composed.
- **D-037 (P4)** Numeric guardrail: a number matches if within 1% of an evidence value or equal to it rounded to the shown decimals; identifiers/dates that occur verbatim in the evidence and L0–L3 tokens are stripped first.
- **D-038 (P4)** Mock fault injection (`_mock_fault`) is keyed separately in the cache so tests never poison real entries. Bus `read` gained sim_date/zone_id/date_from filters (+ index) for tool queries.
- **D-039 (P5/P6)** `thresholds.t2_rule` added: `f1_episode` (spec, default) | `f1_day`. Baseline cut-offs use the same rule. Choice deferred to CP2 (`docs/cp2_packet_*.md` shows both on validation). Observed: `f1_episode` selects always-on alerting in both regions.
- **D-040 (P5)** Fault injection via `agents.control`: `llm_offline` (verifier → fallback, composer → template), `drop_zone` (sensors skip a zone → QualityAgent flags missing); Kill/Restart RainSensor via the sqlite registry pid/cmd. The dashboard writes only `alerts.ack`, `agents.control` and a `quality.flags/agent_restarted` note.
- **D-041 (P5)** Dashboard auto-refresh uses `st.fragment(run_every=2)`; truth overlay shows only closed days (last 14). Smoke-tested with Streamlit AppTest + live health probe.
- **D-042 (P6 prep)** Demo scenarios for the test period are PROPOSED from weather and quakes only (wettest / driest 45-day window, largest quake ≤100 km) — no test labels read; activated only after CP2.
