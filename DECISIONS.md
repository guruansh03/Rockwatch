# DECISIONS

- **D-001 (P0)** Exact-day event = `Date_Min` set and (`Date_Max` empty **or `Date_Max == Date_Min`**). Same-day range carries no extra uncertainty; simplest valid reading. Folded into `exact`; revisit at CP1.
- **D-002 (P0)** `Date_Max < Date_Min` rows: swap; count reported in profile.
- **D-003 (P0)** `Lon_W` sign: if >50% of values positive, negate whole column; residual positive count reported.
- **D-004 (P0)** Type family: lowercase substring match, priority fall > flow > slide > unknown; nonempty unmatched → `other`, empty → `unknown`. "debris avalanche" → flow. Exclusions (gully, avalanche chute, snow avalanche, sinkhole, subsidence, erosion) checked first. Table in `config/default.yaml`; top-40 raw LS_Type→family mapping printed in profile for CP1 review.
- **D-005 (P0)** Region unit = square bbox (2° / 3°, 0.5° step) over 0.25° zone centres, greedy non-overlapping, ranked by C≥C_min exact-dated positive zone-days since 1950. No state polygons (no geopandas). Inventory names shown for state context.
- **D-006 (P0)** Split proposal: boundaries at 60/20/20 cumulative positive-zone-day quantiles, 30-day gap after train and val; start 1950-01-01; end = last event date in region. Heuristic thresholds ≥150 total / ≥30 test (enough for bootstrap CIs with ~dozens of storm clusters); storm-cluster counts also reported since effective sample size = clusters, not zone-days.
- **D-007 (P0)** Sandbox egress initially blocked data hosts → stopped per §1/§3; user downloaded inventory + DS746 natively. Open-Meteo + ComCat now reachable from local VM.
- **D-008 (P0)** v3 zip ships two CSVs (`us_ls_v3_point.csv` 310,774 rows, `us_ls_v3_poly.csv` 680,497 rows). Loader concatenates both, adds `geom`. `Notes`, `Inv_URL` never loaded. `Lon_W` already negative → no flip.
- **D-009 (P0)** Regions ranked by exact-dated C≥3 positive zone-days **excluding** EQ-triggered inventories (28,922 of 48,093 exact C≥3 events are "USGS Earthquake-Triggered Ground Failure": few single days with hundreds of zone-days → tiny effective sample, not rain/thermal-forecastable). EQ events in-region still reported per split; kept for the with/without-EQ breakdown.
- **D-010 (P0)** Train start = Jan 1 of first year with ≥ max(2, 0.1×median annual) positives (reporting-coverage start). Zone-days before an inventory starts reporting are not true negatives. Split end = last positive in region.
- **D-011 (P0)** Type map additions after seeing real values: `mudslide`, `torrent`, `debris_flow` → flow; `rock_fall`, `rock avalanche`, `rock and ice avalanche` → fall (rock-origin; flag at CP1); `manmade fill` excluded. Dates after 2025-12-31 (1 row, 2041) → undated.
- **D-012 (P0)** Yosemite DS746 parsed from `Master` sheet (header row found by "Year"); exact = Y/M/D all present; narrative/reference columns dropped (untrusted). No coordinates → single valley zone.
